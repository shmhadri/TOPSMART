# Workspace Customization Rules

## 1. Curriculum Integration Standard Workflow
Whenever a user requests to add, modify, or extend a curriculum, or add new grade levels/lessons:
1. **Always generate worksheets** (`unitX-worksheets.html`) with A4 style page-break printing layouts, checked interactive answers, and traditional HTML table formatting for Word export downloads.
2. **Always generate teacher printables & classroom strategies** (`unitX-printables.html`) including double-sided flashcards and domino matching games.
3. **Always generate structured PowerPoint slide players** (`unitX-presentation.html`) with 5 slides per lesson (Title, Warm-up/Brainstorming, Content/Dialogue, Concept Check Questions, Classroom Game) and a button to export to real PowerPoint `.pptx` files using `PptxGenJS`.
4. **Always integrate the Wheel of Names** (`wheel.html`) link in the header topbars and sidebar menus.
5. **Always preserve the custom 4-color visual identity** and Tajawal/Outfit typography.
